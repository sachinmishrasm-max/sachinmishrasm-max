## 🚀 Featured Projects

### 🌌 [Navigator — AI-Powered Incident War Room](https://github.com/sachinmishrasm-max/Navigator-AI-Incident-War-Room)

An AI-powered incident investigation platform designed to help engineering and SRE teams investigate production incidents through a unified workspace.

- 🧠 Uses Groq and Llama 3.3 70B for AI-assisted incident analysis and root-cause hypotheses.
- 🔗 Correlates incident signals across tools such as GitHub, PagerDuty, Datadog, Sentry, Slack, and Linear through Coral SQL.
- ⚡ Provides real-time incident updates using WebSockets.
- 📝 Generates structured Markdown postmortems and supports incident-response workflows.

**Tech Stack:** Next.js 15 · React 19 · TypeScript · Node.js · Express · Tailwind CSS · Groq · Coral SQL · WebSockets

### 🧪 [ReactionAI — AI-Powered Chemistry Learning](https://github.com/sachinmishrasm-max/reactionai)

An AI-powered chemistry learning workspace that makes complex chemistry concepts easier to understand through concise, accessible explanations.

- 💡 Explains chemical reactions, mechanisms, molecules, and SMILES strings.
- 🌐 Supports English, Hindi, and bilingual explanations.
- 🎓 Offers Student and Research learning modes.
- 🔐 Routes AI requests through server-side API handlers to keep provider credentials out of the browser.

**Tech Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Groq API · Vercel

### 🩺 MediMeet — Online Doctor Consultation Platform

- 📅 Supports doctor discovery and appointment-booking workflows.

- 📱 Provides a responsive interface for a smoother user experience.

**Tech Stack:** Next.js · Tailwind CSS · ShadCN UI · Prisma ORM · Neon DB · Vonage · WebRTC
